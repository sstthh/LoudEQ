# 响度均衡器 LoudEQ

VibeCoding
系统级实时响度均衡：把不同软件、不同内容的响度统一到用户设定的**绝对响度目标**（LUFS，ITU-R BS.1770 国际标准）。解决"切换软件声音忽大忽小""短视频响度战争"等问题。

- 单文件 `LoudEQ.exe`（约 53KB），内存占用约 20MB，CPU 占用约 1~2%
- 输入比目标安静 → 自动提升（最多 +12 dB）；比目标响 → 自动压低（最多 -30 dB）
- 自带实时 LUFS 表、托盘常驻、开机自启、防振荡设计（含数值自检）
- 运行要求：Windows 10/11（.NET Framework 4.8 为系统自带组件，无需安装）

---

## 一、原理

Windows 不允许普通软件截取并重写系统混音（loopback 只能"监听"，重新播放会造成双声）。本软件采用**虚拟声卡路由**架构（与 Voicemeeter 同类）：

```
所有软件 ──> [CABLE Input 虚拟声卡] ──> CABLE Output（本软件捕获）
     ──> K 加权响度测量（BS.1770 瞬时响度，400ms 窗）──> 前馈增益（升/降）
     ──> 前瞻限幅器（防削波）──> [真实声卡/耳机]
```

启用时本软件自动把系统默认播放设备切换到 CABLE Input，退出时自动恢复原设备。若运行中发现默认设备被手动改走，界面会提示并可一键"恢复路由"。

## 二、安装（每台电脑一次，约 1 分钟）

1. 解压 `installer\VBCABLE_Driver_Pack45.zip`（VB-Audio 官方免费虚拟声卡驱动，[官网](https://vb-audio.com/Cable/)）
2. 运行 `VBCABLE_Setup_x64.exe`（需管理员权限；静默安装命令：`VBCABLE_Setup_x64.exe -i -h`）
3. 运行 `LoudEQ.exe`

## 三、使用

- **目标响度**：滑杆 -40 ~ 0 LUFS（步进 0.5）或右侧**数字框直接键盘输入**，预设：-23 广播 / -18 电影 / -16 默认 / -14 流媒体；实时生效，无需重启
- **响度表**：显示**输出响度**（输入+增益，即均衡结果）；绿色=输出接近目标；蓝色=正在提升；橙色=正在压低；红色=严重超标；白线=目标标记。增益范围：提升最多 +12dB、压低最多 -30dB（不对称：抬多了会放大噪声底）
- **输出音量**：虚拟声卡接管后，键盘音量键控制的是 CABLE 的音量（对处理后的声音无效），请用界面滑杆
- 关闭窗口 = 最小化到托盘；托盘菜单退出；勾选"开机自启"写入注册表 Run 键
- 首次运行若提示"未检测到虚拟声卡"：装好驱动后程序每 3 秒自动重试，无需重启

## 四、防振荡设计（自检可验证）

1. **前馈结构**：增益 = 目标 − 实测输入，无反馈环路，原理上不可能持续振荡
2. **死区**：目标 ±0.75 dB 内不动作
3. **非对称平滑**：压低快（100ms）、提升慢（600ms）、误差 >8dB 自动加速
4. **静音冻结**：最近 100ms 块低于 -48 LUFS 立即冻结，并**回到 2 秒前的增益目标**——防止背景噪声被抬高，也防止下一段响亮内容在收敛前"冲出"半秒巨响
5. **增益钳位**：[-30, +12] dB
6. **前瞻限幅器**：3ms 前瞻、上限 -1.5 dBFS，+12dB 提升也不会削波
7. **瞬态抑制器**：枪声等突然变响——5ms 快速包络对比 2 秒环境参考，高出 10dB 立即削减（5~10ms 生效，起始 20dB+），连发则由响度主路径接棒；只抓瞬态、不碰正常音乐动态
8. **缓冲管理**：重采样率恒为 1.0（**音调不变**）；内容开始时若缓冲过浅自动注入 30ms 静音（发生在静音期，听感无损）；真实硬件 <0.1% 的时钟漂移以 ≤0.05%/5 秒的微步修正（每步 ≤0.9 音分，不可闻）

数值自检（无需声卡）：`LoudEQ.exe /selftest`，结果写入 exe 旁的 `selftest-result.txt`（11 项：K 加权校准、收敛、无振荡、死区、静音保持、阶跃、限幅）。

## 五、常见问题

| 问题                          | 处理                                                                                                                                                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 音量键不起作用                | 键盘音量键现在控制的是 CABLE 虚拟声卡，请用界面"输出音量"滑杆                                                                                                                                                                  |
| 声音有延迟                    | 本软件自身约 35~45ms（30ms 缓冲 + 3ms 流周期 + 3ms 限幅前瞻）；其余来自虚拟声卡与 Windows 音频栈。若仍感明显，可尝试 VB-CABLE HiFi 版（内部缓冲更小）。真正的近零延迟需要驱动级 APO 方案（如 Equalizer APO），属另一条技术路线 |
| 系统提示"麦克风正在使用"      | 正常现象：本软件打开了虚拟声卡的录音端点（CABLE Output 属"录音设备"），Windows 对任何录音活动都会显示麦克风图标。**真实麦克风完全不受影响**（Voicemeeter 同样如此）                                                            |
| 提示"捕获被拒绝 (0x80070005)" | Windows 麦克风隐私设置拦截：设置 → 隐私 → 麦克风 → 打开"允许应用访问你的麦克风"与"允许桌面应用访问你的麦克风"。程序每 3 秒自动重试，打开即恢复                                                                                 |
| 退出后电脑没声音              | 默认设备可能停在 CABLE Input：重新运行本软件再退出即可自动恢复；或到 声音设置 手动切回扬声器                                                                                                                                   |
| 显示"未检测到虚拟声卡"        | 先安装 VB-CABLE 驱动；程序每 3 秒自动重试                                                                                                                                                                                      |
| 程序崩溃后没声音              | 重新运行 LoudEQ.exe 再正常退出即可恢复默认设备                                                                                                                                                                                 |

命令行参数：`/log` 写日志到 `%APPDATA%\LoudEQ\loudEQ.log`；`/quit` 让已运行的实例优雅退出（自动恢复默认设备）；`/selftest` 数值自检。

## 六、多台电脑部署

把 `LoudEQ.exe` + `installer` 文件夹拷到目标电脑（Windows 10/11）：装驱动 → 运行 exe。exe 为 AnyCPU 单文件，无需任何运行时。

## 七、卸载

1. `VBCABLE_Setup_x64.exe -u` 卸载驱动（或设备管理器删除 VB-Audio Virtual Cable）
2. 删除 LoudEQ.exe 及 `%APPDATA%\LoudEQ`（配置与日志）

## 八、构建

```powershell
.\build.ps1
```

使用 Windows 自带的 .NET Framework 4.8 编译器（csc.exe）编译，无需安装任何 SDK。源码在 `src\`（C# 7.3，约 1700 行）：`CoreAudio.cs`（WASAPI COM 接口）、`AudioEngine.cs`（捕获→DSP→渲染引擎）、`Dsp.cs`（K 加权/响度计/增益控制/限幅/重采样）、`MainForm.cs`（GUI）、`Selftest.cs`（数值自检）。

**已知限制**：独占模式应用（极少数老游戏）可能绕过虚拟声卡路由；本软件运行期间需保持后台运行（类似 Voicemeeter 的使用方式）。
